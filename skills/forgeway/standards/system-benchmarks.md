# 系统基准测试

用于需要比较版本、验证系统边界或评估负载的项目。按项目实际入口选择下表条目。业务合同、测试数据和性能目标由项目持有。[证据与完成定义](evidence.md) 约束交付证据；界面呈现按[前端视觉验收](frontend-css.md#verification)检查，前端耗时与资源指标采用[前端性能验证](frontend-performance-verification.md)。

## 开跑前冻结

记录工作树或快照、未提交文件的内容指纹、题库、夹具、评分条目、运行器与复核器版本。标出操作者、复核者、环境、数据集、服务边界、允许的效果、资源上限和清理方法。写明每一项的输入、操作、预期可观察结果、取证位置。容量和延迟目标引用已接受的 SLO；缺少 SLO 时只形成测量基线。

## 基准条目

项目 MUST 为选用的条目记录适用范围、执行条件和对应判据的实测结果。缺少必要证据时 MUST 标为待验；项目 MAY 增加与业务负载相符的场景。

| ID | 测试内容与用例设计 | 主要判据 |
|---|---|---|
| B01 | 正常流程。通过真实入口操作，确认响应、实际结果及下一步能消费的状态。 | 独立预期与结果逐字段一致，数据归属正确。 |
| B02 | 边界。覆盖空集、首末页、恰达上限、超出一单位、异常输入和一个正常对照。 | 有效边界保留原语义；拒绝后数据和下一次正常调用仍正确。 |
| B03 | 防御性对抗。使用合成身份、无权限状态、矛盾回执或内容被替换的测试副本，分别验证拒绝行为。 | 不能把缺失权限、错误对象或损坏证据计作通过，原对象不被改变。 |
| B04 | 并发。至少两个独立会话共享同一资源，区分并发读、状态转换和发布顺序。 | 明确合法终态集合、隔离范围、重复操作语义；同时请求不能替代对最终状态的核查。 |
| B05 | 有界压力与恢复。预热后跑低负载、分级升压、回落到相同低负载。记录并发、请求数、持续时间、开放或闭合负载、超时及中止条件。 | 每档核对正确率与数据不变量。记录拒绝/超时率、吞吐、P50/P95/P99、最大值与资源占用。小样本尾部分位仅供观察。 |
| B06 | 性能优化。先用分段计时、执行计划或剖析定位成本。同数据、同输出、同资源限制对照基线与候选，交替运行并重复采样。 | 验证输出等价与错误率，比较同并发下的延迟和吞吐；列明计时包含的层、波动与收益代价。 |
| B07 | 中断、重试与持久化。完成一次操作，再测试会话注销、服务重启、重复读取或项目支持的写入重试。 | 已提交结果仍可读取，失效会话保持失效；幂等写场景需核对实际写入次数。 |
| B08 | 评测与复核。区分输入明示要求、技能需主动推导的要求和仅供评分的条件。逐项检查交付物、执行效果和残留未验事项。 | 冻结题面与判据各自有哈希；保留原始、复核和结构校验三个退出码。同一轮内统计通过率。 |
| B09 | 可复现性。正例回放、单因素负对照、原件复查和不同阶段的摘要核对。 | 各产物绑定输入及原始轨迹；未记录身份时只声明复核步骤独立。区分快照完整性与当前工作树一致性。 |

## 常见问题与记录

- **两次定向重跑能否合并为整轮结果？** 按各次基线单列；完整通过需要同一轮完整集合。
- **如何判定并发或性能回归？** 先复查输入、并发模型、缓存、连接复用和测量层。错误内容即使响应很快也算失败。没有同条件对照时保留观察值。
- **如何处理部分证据？** 记录哪些字段缺失、影响哪个结论，以及可恢复条件。代码片段可编译与交付物已充分解释原因是不同判据。
- **如何登记真实问题？** 保留案例 ID、责任模块、基线、预期与实际、首次失败及最小复验、影响、原始证据和修复前对照。将性能假设、已证实缺陷和未覆盖场景分别记录，再决定修复范围。
